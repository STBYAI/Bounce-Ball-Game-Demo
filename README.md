# 弹力球游戏演示

一个使用Python和Pygame库开发的弹力球游戏演示版本。

## 游戏功能

### 两种游戏模式
1. **自由模式**
   - 球初始静止在屏幕中心
   - 鼠标变为一条横线，始终朝向球
   - 球碰到屏幕边缘会反弹并减速
   - 没有重力和时间限制

2. **重力模式**
   - 球受重力影响，会一直往下掉
   - 鼠标作为球拍，将球弹起
   - 球碰到边缘会反弹，但不会减速
   - 成功弹球可获得10分
   - 球落地则游戏结束，显示最终分数

## 操作方法

- **移动鼠标**：控制球拍位置，球拍始终朝向球
- **点击鼠标**：
  - 点击"自由模式"或"重力模式"按钮切换游戏模式
  - 游戏结束后点击"重新开始"按钮重启游戏

## 安装和运行

### 环境要求
- Python 3.x
- Pygame库

### 安装步骤
1. 安装Python 3.x
2. 安装Pygame库：
   ```bash
   pip install pygame
   ```

### 运行游戏
在项目根目录下运行：
```bash
python main.py
```

## 游戏规则

### 自由模式
1. 球初始位置在屏幕中心
2. 移动鼠标靠近球，球拍会自动朝向球
3. 鼠标碰到球时，球会被弹走
4. 球碰到屏幕边缘会反弹并减速
5. 游戏可以无限进行

### 重力模式
1. 球初始位置在屏幕中心
2. 球受重力影响，会一直往下掉
3. 移动鼠标到球下方，球拍自动朝向球
4. 球碰到鼠标球拍时会被弹起，同时获得10分
5. 球碰到屏幕边缘会反弹，但不会减速
6. 如果球落到屏幕底部，则游戏结束
7. 游戏结束后可以点击"重新开始"按钮继续游戏

## 技术实现

- **物理引擎**：简单的2D物理系统，包括重力、碰撞检测和反弹
- **碰撞检测**：线段与圆的碰撞检测算法
- **渲染**：使用Pygame库进行2D图形渲染
- **架构**：采用MVC模式，将游戏逻辑、渲染和控制分离

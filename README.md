# Bounce Ball Game

一个基于Python和Pygame的弹力球游戏演示版本，包含两种游戏模式。

## 功能特点

### 游戏模式

1. **自由模式**
   - 球初始静止在屏幕中心
   - 没有重力影响
   - 鼠标控制的球拍会始终朝向球
   - 球碰到屏幕边缘会反弹并减速
   - 玩家可以自由地用鼠标拍球

2. **重力模式**
   - 球受重力影响，会自然下落
   - 球碰到屏幕边缘会反弹但不会减速
   - 玩家需要用鼠标在球下面接住并弹起球
   - 成功弹起球可以获得10分
   - 如果球落地，游戏结束

### 游戏控制

- **开始菜单**：
  - 按 `1` 键选择自由模式
  - 按 `2` 键选择重力模式

- **游戏中**：
  - 移动鼠标控制球拍位置
  - 按 `M` 键切换游戏模式
  - 重力模式下游戏结束后，按 `SPACE` 键重新开始
  - 按 `ESC` 键退出游戏

## 安装和运行

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行游戏

```bash
python main.py
```

## 技术实现

- **游戏逻辑**：负责球的物理运动、碰撞检测、分数计算等
- **游戏渲染**：负责所有图形元素的绘制
- **主类**：处理用户输入、协调逻辑和渲染

## 物理特性

- **自由模式**：球的速度会在碰到屏幕边缘时衰减
- **重力模式**：球始终受到向下的重力影响
- **球拍碰撞**：球碰到球拍时会根据碰撞角度反弹
